# Анализ логистики маркетплейса

Учебный проект для анализа заказов и оценки основных показателей доставки. В репозитории собраны данные, Excel-файл с анализом и SQL-скрипты для работы с тем же набором данных в PostgreSQL.

> Данные в проекте демонстрационные и сгенерированы для обучения. Они не относятся к Ozon, RWB или другим реальным компаниям.

## Что позволяет изучить проект

- объём заказов и распределение по статусам;
- количество доставленных и отменённых заказов;
- долю доставок, выполненных в обещанный срок;
- среднее время доставки и среднюю величину задержки;
- сравнение складов и регионов;
- изменение количества заказов по месяцам;
- поиск заказов с наибольшей задержкой.

## Файлы

| Файл | Назначение |
|---|---|
| `orders.csv` | Демонстрационный набор из 1 000 заказов |
| `marketplace_logistics_analysis.xlsx` | Таблица заказов, расчёты и сводный анализ в Excel |
| `01_create_table.sql` | Создание таблицы `public.orders` в PostgreSQL |
| `02_analysis_queries.sql` | SQL-запросы для расчёта показателей и сравнения складов и регионов |

## Используемые инструменты

- **Microsoft Excel:** фильтрация, сортировка, сводные таблицы, `ВПР` / `XLOOKUP`, `СУММЕСЛИ`, `СУММЕСЛИМН` и расчёт показателей.
- **PostgreSQL:** `SELECT`, `WHERE`, `COUNT`, `AVG`, `GROUP BY`, `ORDER BY`, условная агрегация, CTE и оконная функция `DENSE_RANK`.

## Как открыть проект в Excel

1. Скачайте `marketplace_logistics_analysis.xlsx`.
2. Откройте файл в Microsoft Excel.
3. Перейдите на лист с исходными заказами и листы со сводным анализом.
4. Используйте фильтры и сводные таблицы, чтобы изучить заказы по статусам, складам и регионам.

## Как запустить SQL-анализ в PostgreSQL

1. Создайте базу данных, например `marketplace_analytics`.
2. Откройте Query Tool в pgAdmin 4.
3. Выполните скрипт `01_create_table.sql` — он создаст таблицу `public.orders`.
4. Импортируйте `orders.csv` в таблицу `public.orders` через меню **Import/Export Data**. Формат — CSV, кодировка — UTF-8, параметр Header включён, разделитель — запятая.
5. Откройте `02_analysis_queries.sql` и выполняйте запросы по очереди.

## Примечание к результатам

Все рассчитанные значения относятся только к демонстрационному набору. Они показывают, как можно организовать анализ логистических показателей, но не являются оценкой работы реального маркетплейса. Различия между складами и регионами сами по себе не объясняют причины задержек — для этого потребуются дополнительные данные о маршрутах, этапах обработки и перевозчиках.
